The gate blocked on one finding, not on every problem in the file. It named the pre-existing error and said explicitly not to fix it. Asking a model to clean up prose it did not write is how a writing gate becomes something people switch off — across a 167-file corpus, that single change took the block rate for an ordinary edit from 72% to 2%.
